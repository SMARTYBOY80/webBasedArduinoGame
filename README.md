# MacSmarty Flappy Bird
>  [!IMPORTANT]
> This project was made using the **Arduino UNO** micro-controller board.

> [!TIP]
> You will need 6 hardware components to connect to your board for the program to run smoothly.
> 1. LEDs
>   - x1 Green
>   - x1 Red
> 2. Resistors
>   - x2 100Ω
> 3. Buttons
>   - x2 Pushbuttons
